# TriTraining Training

版本：V0.1
日期：2026-06-14
状态：模块 training 真源入口初始化

## 定位

本目录只负责 `TriTraining` 模块自己的 training 内容。

它用于沉淀：

- 培训学院模块导读
- lesson / lab contract
- 课程图谱与课程体系
- 模块内部流程
- 与 `TriAvatar` / `TriStaciss` 的协作接口说明

## 边界

- 不代替 `TriTraining` 的 `docs/product/`、`docs/engineering/`、`docs/workflow/`、`docs/registry/` 真源
- 不代替 `TriMetaverse/docs/training/tritraining/` 中央聚合包
- 宿主侧如需 published copy，应按真源发布链进入 `TriTraining-copilot-host-assets`
